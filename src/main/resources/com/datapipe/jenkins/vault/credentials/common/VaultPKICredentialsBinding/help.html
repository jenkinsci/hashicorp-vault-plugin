Issues an ephemeral X.509 certificate from the Vault PKI secrets engine and writes the PEM-encoded components to temporary files in the build workspace.

Certificate PEM variable
Environment variable set to the path of the PEM file containing the issued certificate (-----BEGIN CERTIFICATE-----).
Private key PEM variable
Environment variable set to the path of the PEM file containing the private key. The file is created with 0400 permissions on POSIX systems. Do not print the file contents to the build log.
CA certificate PEM variable
Environment variable set to the path of the PEM file containing the issuing CA certificate.

All three files are automatically deleted when the withCredentials block exits.

Tip: For tools that accept a PKCS12 keystore, use the standard Certificate binding (keystoreVariable / passwordVariable) instead – it also works with Vault PKI credentials.
